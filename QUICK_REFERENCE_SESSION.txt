## 🚀 How to Use in New Pages

```php
<?php
// 1. Include centralized session (always at top)
include '../includes/session.php';
include '../database/config.php';
include '../includes/helpers.php';

// 2. Check access
requireAdmin();

// 3. Your page logic here

$page_title = 'Your Page Title';

// 4. Set breadcrumb
$breadcrumbs = [
    'Dashboard' => 'dashboard.php',
    'Your Page' => null  // null = current page
];
?>

<?php include '../templates/header.php'; ?>

<div class="container-fluid mt-4">
    <!-- 5. Add navigation components -->
    <?php include '../includes/breadcrumb.php'; ?>
    <?php include '../includes/back_button.php'; ?>
    
    <!-- Your content here -->
</div>

<?php include '../templates/footer.php'; ?>
```

## 🐛 If Issues Occur

**Problem: Still seeing warnings**
- Clear browser cache
- Reload page with Ctrl+F5
- Check file was saved correctly

**Problem: Navigation not showing**
- Ensure `breadcrumbs` array is set
- Check includes are in correct order
- Verify file paths are correct

**Problem: Buttons not styled**
- Ensure Bootstrap CSS is loaded
- Check Font Awesome is loaded
- Reload page
