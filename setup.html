Go to Login Page

Step 4 Explore Features

After logging in, explore these admin features:

  • Manage Requests - Review and approve parishioner requests
  • Sacramental Records - Manage baptism, communion, confirmation, and marriage records
  • Manage Users - Control user accounts and status
  • Announcements - Post announcements and events
  • Dashboard - View system statistics and quick actions

Project Structure

Location: c:\xampp\htdocs\ParishSystem\
Admin Panel: http://localhost/ParishSystem/admin/
User Panel: http://localhost/ParishSystem/users/
Main URL: http://localhost/ParishSystem/

Database Tables Created
  • users - System users (admin/parishioner)
  • requests - Certificate and service requests
  • baptism_records - Baptism information
  • first_communion_records - First Communion records
  • confirmation_records - Confirmation records
  • marriage_records - Marriage information
  • announcements - Church announcements
  • reservations - Church reservations
  • notifications - User notifications
  • audit_log - System activity log

Troubleshooting

Database error? Make sure MySQL is running in XAMPP.

404 error? Verify the URL: http://localhost/ParishSystem/

Login issues? Try clearing your browser cache or using incognito mode.
