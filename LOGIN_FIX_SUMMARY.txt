## 🛠️ Troubleshooting Guide

### Still getting "Invalid email or password"?
1. Run `verify-login.php` to check system status
2. Run `debug-login.php` to verify password hash
3. Check email is exactly: `admin@parish.com`
4. Verify account status is "active" in database

### Can't redirect to dashboard?
1. Clear browser cookies
2. Check session_start() is at top of page
3. Verify `$_SESSION['role']` is set correctly
4. Check file permissions on dashboard files

### Password reset needed?
1. Run `fix-password.php`
2. Click "Reset Admin Password" button
3. Credentials reset to: admin@parish.com / admin123
