================================================================================
  STEP 1: VERIFY XAMPP IS RUNNING
================================================================================
1. Open XAMPP Control Panel
2. Make sure Apache is running (green "Running" text)
3. Make sure MySQL is running (green "Running" text)
4. If not, click "Start" for both services

================================================================================
  STEP 2: INITIALIZE THE DATABASE
================================================================================
1. Open your web browser
2. Go to: http://localhost/ParishSystem/setup.html
3. Read the setup guide
4. Click the GREEN "Initialize Database" button
5. Wait for success message
6. You should see:
   - "Database setup completed successfully!"
   - Admin Email: admin@parish.com
   - Admin Password: admin123

If you get an error:
- Make sure MySQL is running
- Go to: http://localhost/phpmyadmin
- Verify you can access it
- Try the installer again

================================================================================
  STEP 3: LOGIN TO THE SYSTEM
================================================================================
1. Open: http://localhost/ParishSystem/
2. You'll be redirected to the login page
3. Use these credentials:
   - Email: admin@parish.com

4. Click "Login"

================================================================================
  TROUBLESHOOTING
================================================================================

Problem: "Connection failed" or database error
Solution:
  1. Start MySQL in XAMPP
  2. Run the database installer again
  3. Check http://localhost/phpmyadmin

Problem: Login page shows 404 error
Solution:
  1. Make sure Apache is running
  2. Check URL: http://localhost/ParishSystem/auth/login.php
  3. Verify folder: c:\xampp\htdocs\ParishSystem exists

Problem: Cannot login even with admin credentials
Solution:
  1. Clear browser cache
  2. Try incognito/private mode
  3. Verify MySQL is running
  4. Run database installer again

Problem: Request approval not working
Solution:
  1. Make sure you're logged in as admin
  2. Check the manage-requests.php page
  3. Click on "Manage Requests" from dashboard
